# Repositório e atualizações

Repositório deste projeto: https://github.com/Douglaslopes24/Casanotify-tv-

A branch `main` contém o código e os downloads. Para instalar via HACS, adicione esse endereço como repositório personalizado da categoria **Integração**. Não há alegação de inclusão no catálogo padrão do HACS.

Para contribuir pelo computador, clone o repositório, altere os arquivos, execute os testes e envie um commit pelo seu GitHub autenticado. A documentação de instalação está em `INSTALACAO.md`.

A assinatura privada original não está no GitHub. Para produzir APKs que atualizem a instalação existente, use o backup privado de `keystore.properties` e da chave com o script Android. Não envie senhas, tokens ou arquivos de assinatura para commits, issues ou conversas públicas. Compilar sem a chave original gera outro certificado, incompatível com atualização sobre a instalação original.

Ao publicar uma atualização, ajuste manifest, versões do APK, changelog e documentação; gere APK e ZIP da integração; atualize `downloads/SHA256SUMS`; verifique os testes e a instalação em hardware.
